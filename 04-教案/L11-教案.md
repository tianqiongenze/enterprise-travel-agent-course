# 第 11 次课教案：TDD 与契约测试

| 项 | 内容 |
|---|---|
| 周次 | 第 11 周 |
| 学习领域 | LF5 质量保障（11-13 周） |
| 学时 | 4 学时（180 分钟） |
| 场所 | 【校】学校教室/机房 |
| 教学方法 | 双元制六步法 + 费曼时刻 + 布鲁姆分层 |

## 一、教学目标（布鲁姆分层）

- **[应用]** 按先红后绿流程新增一个测试用例 —— Apply：能够在真实环境执行
- **[分析]** 分析项目测试分层（单元/契约/功能/BDD） —— Analyze：能够拆解与归因
- **[理解]** 解释 CI 阈值即门禁的思想 —— Understand：能够解释与举例

## 二、重点与难点

- **重点**：pytest 风格（真实测试文件）；120 用例全绿基线；测试即文档
- **难点**：测试先行的心智转换

## 三、教学过程设计（双元制六步法，180 分钟）

| 步骤 | 德语 | 时长 | 活动设计 |
|---|---|---|---|
| 资讯 | Informieren | 30min | 项目测试全景（Python 120 / Go race / maven / BDD）；TDD 三律 |
| 计划 | Planen | 20min | 选题：给 multilevel_cache 或 token_bucket 加用例 |
| 决策 | Entscheiden | 15min | 用例断言确认（先写失败断言） |
| 实施 | Durchführen | 70min | 写失败用例 → 跑红 → 最小实现 → 跑绿 → 重构 |
| 检查 | Kontrollieren | 30min | 全量回归 120 用例必须全绿；互查命名与断言 |
| 评价 | Bewerten | 15min | 费曼×3 + 总结测试金字塔 |

## 四、费曼学习法环节

- **费曼题目**：讲清：先写测试为什么反而更快
- **规则**：抽签 3 人 × 3 分钟；禁用未解释术语（听众举红牌即重讲）；当场补漏成功得满分
- **评分**：清晰度 2 分 + 类比质量 2 分 + 应对追问 1 分（计入过程考核素质分）

## 五、布鲁姆达成检验（随堂快测）

- **Q：TDD 三律是什么？**
  - A：没有失败测试不写产品代码 / 只写刚好失败的测试 / 只写刚好通过的代码
- **Q：项目 Python 回归多少用例？**
  - A：120（scripts/run_python_tests_ci.py）
- **Q：Go 测试的门禁参数？**
  - A：go test -race（竞态检测）
