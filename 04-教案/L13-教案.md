# 第 13 次课教案：K6+Locust 压测实战

| 项 | 内容 |
|---|---|
| 周次 | 第 13 周 |
| 学习领域 | LF5 质量保障（11-13 周） |
| 学时 | 4 学时（180 分钟） |
| 场所 | 【企】合作企业机房（真实集群） |
| 教学方法 | 双元制六步法 + 费曼时刻 + 布鲁姆分层 |

## 一、教学目标（布鲁姆分层）

- **[应用]** 执行一轮 K6 压测并解读 thresholds 结果 —— Apply：能够在真实环境执行
- **[分析]** 分析 50VU 与 200VU 两轮数据差异的瓶颈 —— Analyze：能够拆解与归因
- **[评价]** 评价阈值门禁设计（P95<300ms） —— Evaluate：能够依据标准评判

## 二、重点与难点

- **重点**：k6 Job 集群内执行；Locust master/worker；基线：252 req/s、P95 262ms
- **难点**：为什么 200VU 吞吐反而下降（单 pod CPU limit）

## 三、教学过程设计（双元制六步法，180 分钟）

| 步骤 | 德语 | 时长 | 活动设计 |
|---|---|---|---|
| 资讯 | Informieren | 30min | 压测报告解读（三轮数据表）；k6 与 locust 分工 |
| 计划 | Planen | 20min | 小组定 VU 档位与观察指标 |
| 决策 | Entscheiden | 15min | 压测报备与安全边界（不轰炸生产 ns） |
| 实施 | Durchführen | 70min | 复跑 K6 Job → 采集 metrics → Locust UI 一轮 → 数据填表 |
| 检查 | Kontrollieren | 30min | 与基线对比（正负 15% 内合格）；异常数据复盘 |
| 评价 | Bewerten | 15min | 费曼×3 + 各组数据对比点评 |

## 四、费曼学习法环节

- **费曼题目**：讲清：P95 和平均值哪个重要（长尾体验）
- **规则**：抽签 3 人 × 3 分钟；禁用未解释术语（听众举红牌即重讲）；当场补漏成功得满分
- **评分**：清晰度 2 分 + 类比质量 2 分 + 应对追问 1 分（计入过程考核素质分）

## 五、布鲁姆达成检验（随堂快测）

- **Q：50VU 稳态吞吐和 P95？**
  - A：252 req/s、262ms
- **Q：200VU 时瓶颈在哪？**
  - A：单 pod CPU limit 2 核 + Python GIL
- **Q：k6 阈值失败会怎样？**
  - A：退出码非 0 → CI 门禁红
