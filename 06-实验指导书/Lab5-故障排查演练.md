# Lab5 故障排查演练（LF6，随 L15 课）

## 目标
使用可观测性指标与 kubectl 定位 3 个预设故障（教师注入），产出排查报告。

## 预设故障（教师现场注入其一）
- 故障 A：某 pod 被删除 → 观察 HPA 自动拉起（自愈）
- 故障 B：TRAVEL_GRAPHQL_MAX_DEPTH 调成 2 → GraphQL 合法查询被误拒（配置事故）
- 故障 C：限流阈值调低至 10 → 连续请求出现拒绝（rejects_total 增长）

## 排查路径（四步法）
1. 现象确认：哪个接口、什么状态码、多少比例
2. 指标定位：/metrics 中哪个指标异常（requests_total? rejects_total? hit_rate?）
3. 根因假设：配置变更？实例异常？依赖故障？
4. 验证修复：kubectl 命令 + 复测
