## 一句话介绍

以一个**真实上线运行的企业级旅游智能体平台**（6 个微服务 + 百万级并发容量设计 + 真实 K8s 集群实测数据）为教学载体，按照德国双元制（Duale Ausbildung）模式本土化设计的项目实战课程：学校学理论、企业做真项目，每周一次"资讯→计划→决策→实施→检查→评价"完整行动循环。

## 课程快速事实

| 项 | 值 |
|---|---|
| 课程名称 | 企业级旅游智能体项目实战（Enterprise Travel Agent Project Practice） |
| 学时/学分 | 64 学时（16 周 × 4 学时）/ 4 学分 |
| 适用专业 | 高职高专：人工智能技术应用、大数据技术、软件技术 |
| 教学模式 | 德国双元制本土化（学校 50% + 合作企业 50%）+ 费曼学习法 + 布鲁姆认知分层 |
| 教学载体 | enterprise-travel-agent 真实项目（Java 网关 + Python 智能体运行时 + 4 个 Go 微服务） |
| 实训环境 | 企业真实 K8s 集群（TiDB 8.5 / Redis 8 / Pulsar / Milvus / Prometheus） |
| 考核 | 过程考核 40% + 企业实践 30% + 期末项目答辩 30% |

## 双元制学习领域（Lernfelder）

| 学习领域 | 周次 | 主题 | 成果物 |
|---|---|---|---|
| LF1 项目认知与企业环境 | 1-2 | 百万并发系统全景、双元制学习法、环境搭建 | 环境就绪检查表 |
| LF2 接口设计与微服务 | 3-5 | REST 契约、GraphQL 查询层、gRPC 契约 | 接口测试报告 |
| LF3 数据工程 | 6-8 | DDD 仓储、读写分离、多级缓存 | 数据层验证报告 |
| LF4 服务治理 | 9-10 | 令牌桶限流、异步削峰队列 | 治理策略实验记录 |
| LF5 质量保障 | 11-13 | TDD/BDD/契约测试、K6+Locust 压测 | 压测报告 |
| LF6 部署运维与交付 | 14-16 | K8s/HPA、可观测性、容量外推、项目答辩 | 答辩 PPT + 交付文档 |

## 同步机制（项目 → 课程）

主项目仓库（enterprise-travel-agent）每次更新后，运行：

```bash
python tools/sync_from_project.py
```

自动把项目最新文档、压测报告、部署清单同步到 `09-项目同步资料/`，并在 `SYNCLOG.md` 记录来源 commit——课程永远基于项目最新真实状态授课。
